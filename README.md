# MiniWrite

**Мини-версия «ворда»:** печать с оформлением, без тяжёлого Word.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 6 — «Текст»** · **день 42 (финал)**.

---

## Что умеет

- жирный / курсив / подчёркивание (Ctrl+B / I / U)
- шрифт и размер (Calibri по умолчанию)
- выравнивание: влево / центр / вправо
- маркированный список
- новый / открыть / сохранить / сохранить как
- формат `.mw` (текст + оформление) и `.txt`
- интерфейс в духе Word: синяя шапка, лента, белый лист
- счётчик слов и знаков в статусной строке
- спросить про сохранение при закрытии

## Запуск

```bat
start.bat
```

или `python -m miniwrite` / `run_miniwrite.pyw`.

Нужен Python 3.10+ с tkinter.
